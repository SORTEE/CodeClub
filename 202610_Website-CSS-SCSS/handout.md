# Follow along: CSS & SCSS live coding

SORTEE Code Club · Part 2 · Cecilia Baldoni

We will style the Part 1 website together. You can code along and see every change live in your browser.

## 1. Install (before the session)

- **Quarto**: <https://quarto.org/docs/get-started/>
- **RStudio** or **VS Code** (with the Quarto extension)
- **Git**: only if you choose Option A below

## 2. Get the website

The website lives in the folder `20260519_WebsiteQuarto` of the repo `SORTEE/CodeClub`.

**Option A: Download ZIP (no Git, no account)**

1. Go to <https://github.com/SORTEE/CodeClub>
2. Click the green **Code** button, then **Download ZIP**
3. Unzip it (for example on your Desktop)
4. **Copy** the folder `20260519_WebsiteQuarto` to a new place and call it `my-site`, so you always have a clean original

**Option B: Clone (if you already use Git)**

```bash
git clone https://github.com/SORTEE/CodeClub.git
cd CodeClub/20260519_WebsiteQuarto
```

Use the HTTPS link, not SSH. Run `git pull` later to get any fixes I push during the session.

## 3. Open the folder

- **RStudio**: open `WebsiteQuarto.Rproj`
- **VS Code**: File → Open Folder → pick the website folder (`my-site`)

## 4. Start the live preview

In the Terminal (RStudio has a Terminal tab; VS Code: Terminal → New Terminal), from inside the website folder:

```bash
quarto preview
```

Your browser opens the site. From now on, every time you **save** a `.qmd`, `.scss` or `.css` file, the page updates by itself.

## 5. What we will do in the session

1. Create a new file called `styles.scss` next to `_quarto.yml`
2. In `_quarto.yml`, change the theme line from

   ```yaml
   theme: flatly
   ```
   to
   ```yaml
   theme: [flatly, styles.scss]
   ```
3. Write our styles in `styles.scss`, save, and watch the page change

## If something doesn't work

| Problem | Try this |
|---|---|
| Nothing changes when I edit | Did you **save** the file? Is `styles.scss` listed in `_quarto.yml`? |
| `quarto: command not found` | Close and reopen the terminal. If it persists, reinstall Quarto |
| Error after editing SCSS | Check for a missing `;` or `}`. The error message names the line |
| Page looks broken or stale | Stop the preview (Ctrl+C) and run `quarto preview` again |
| I'm lost | Copy the original folder again and start fresh. Ask in the chat! |

## Ignore these folders

`_site/`, `_freeze/` and `.quarto/` are generated by Quarto. Never edit them.
